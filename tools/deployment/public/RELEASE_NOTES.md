## `@VERSION@` 竞技场更新

本次 Windows x86_64 完整包更新竞技场读取、客户端恢复和识别资源，发布到 main 并设为 Latest，进入默认 Stable 更新通道。不包含尚在开发中的培育自动出牌与路线功能增量。

### 本次更新

- 修正战斗演出、加载与正式结果读取的衔接。待完成对局先等待正式结果页，命中后才启用赢家读取机会；转场不再占用三帧结果重读额度。演出页 TAP 与短暂通信错误使用同一对局内的有界恢复，重进不会刷新已经消费的额度。
- 结果确认以三个舞台赢家和总胜负为准，分数识别异常不阻断保存。结果成功保存后才离开页面；已保存但尚未回场的对局由客户端承接，避免重复记录或再次发起挑战。
- 没有对手达到配置门槛时，选择预测胜率最高的对手，并明确记录采用了兜底选择；默认70%门槛保持原值，不把兜底选择伪装成达标。
- 改善技能详情的文字连接、标题和弹窗恢复。远距数字隔离只在正文解析失败后执行；正常成功路径不增加污染检查。误关闭的详情优先在原卡位重新打开，仍使用原有恢复预算。
- P道具已读到的完整详情文字优先参与身份与强化状态判断；更新图库和跨分辨率处理，减少不必要的详情访问。全文文字识别（OCR）在同一帧内复用已有文字框，失败的读取与恢复也计入耗时日志。

### 验证范围与已知限制

- 发布前的既有候选曾在一次MaaCLI启动中自主完成四场挑战、胜负记录与回场。该实机结果不代替本次转场修复后的完整流程验收；本次初步修复以真实多阶段页面序列及相关离线回归核验。
- 540×960物理窗口经Maa归一化后可输出720×1280图像，两次己方读取与常用窗口一致；该物理窗口的完整自动挑战仍未通过验收，当前建议继续使用720×1280或更大窗口。
- 已耗尽恢复额度的旧未完成对局会保留记录并停止，升级不会清空记录或返还次数。本版本尚未达到同一版本连续两个游戏日、每天五场的最终日常验收。
- 正式发布不等于日常挑战最终验收完成；全部卡片、跨窗口留出及完整节拍门仍有待验证项。

### 安装与更新

- 下载 `MaaGakumasu-win-x86_64-@VERSION@.zip`，解压到新的独立目录，运行版本内 `deployment\Start-MaaGakumasu-Admin.cmd`。请勿覆盖上游Maa或正在运行的旧目录。
- 已使用独立GKH版本的用户保持默认Stable通道，通过MFA内置GitHub资源更新升级。本版是该通道首个非预发布版本；从旧组合版本首次迁移仍需手动安装完整包。不要切换Beta或Alpha通道，以免选择到数值更高的旧组合版本。
- 完整包更新来源保持为本项目GitHub Releases，沿用MFA原生更新机制；不声明上游MirrorChyan资源身份。pip入口继续只更新Python依赖，RIS引擎与数据继续从其已确认的生产版本成对更新，识别模型和图库随本完整包交付。
- 默认使用目录最新期数、70%配置门槛、2000次模拟和180秒模拟时限。每日挑战可选择首轮重新读取己方，后续场次复用有效缓存。
- 使用说明见[指导中心](@REPOSITORY@/blob/main/guides/README.md)。
