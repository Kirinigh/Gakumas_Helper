## `@VERSION@` 竞技场期数、日志与新卡图库更新

本次补齐反馈日志中的详细记录，修复竞技场组件更新失败后的恢复，并让客户端期数列表跟随 RIS 目录更新。

### 本次更新

- **反馈日志更完整。** 客户端界面继续显示简洁摘要，导出的日志包补齐后台详细记录和失败现场。成员读取失败时保留当时的页面、位置和操作记录，避免回场后只剩一张与故障无关的画面。
- **组件更新失败后自动恢复。** 竞技场模拟组件遇到短暂网络或文件占用问题时会有限次重试；仍失败会保留原始原因，下次启动任务也能重新尝试。
- **期数列表及时更新。** RIS 目录更新后，客户端会补上新期数，标出预览期与最近正式期。开始读取前显示本次实际使用的期数，方便与游戏核对。
- **每个期数只显示一次。** 移除顶部重复的“最新”选项，统一按具体期数选择。旧“最新”选择会转为目录对应的具体期数；已经选定的期数会保留，不会随着下一期上线自动改变。
- **补充新卡识别参考。** 新增技能卡「光り輝く道しるべ」「先へ進む姿」和 P 道具「頂点の輝き」的普通／强化参考，识别模型、算法和阈值保持不变。
- MaaFramework 与 Python 配套包继续使用 **5.13.0**，模拟参数保持不变。

### 使用与更新

- 下载 `MaaGakumasu-win-x86_64-@VERSION@.zip`，完整解压到新目录，运行 `deployment\Start-MaaGakumasu-Admin.cmd`。
- 已使用独立 GKH 版本的用户保持 **Stable** 通道，通过 MFAAvalonia 内置 GitHub 资源更新升级。本版设为 **Latest**。
- 从旧 `vMAJOR.MINOR.PATCH+gkh.*` 组合版本首次迁移，仍需手动下载完整包。请勿切换到 Beta 或 Alpha，这两个通道可能选中编号更高的旧组合版本。
- 完整包从本项目 GitHub Releases 更新。Python 依赖按随包声明安装配套版本；RIS 引擎／数据更新仍使用原有入口。
- 更新后请核对“竞技场期数”。RIS 可能提前提供预览期，列表最高期数不一定是游戏当前期数。
- 详细说明见[使用手册](@REPOSITORY@/blob/main/guides/README.md)。
