## `@VERSION@` 适配 MaaFramework 5.13.0

修复升级 MaaFramework 5.13.0 后，竞技场成员页面有卡片却反复提示读取失败的问题。

### 本次更新

- **适配卡片定位。** MaaFramework 5.13.0 调整了检测图像的等比缩放与补边方式。本版为竞技场技能卡定位补上兼容处理，使原有 `cards.onnx` 模型继续使用对应的输入比例。
- **读卡错误更明确。** 卡组布局无法定位时，提示会指出正在读取的队伍和成员，避免被笼统归为技能卡正文识别失败。详细原因和失败现场仍保留在反馈日志中。
- **保留上一版内容。** 继续使用 v0.3.3 的技能卡与 P 道具图库，以及期数列表、组件恢复和反馈日志修复。
- MaaFramework 与 Python 配套包继续使用 **5.13.0**，竞技场引擎与模拟参数保持不变。

### 使用与更新

- 下载 `MaaGakumasu-win-x86_64-@VERSION@.zip`，完整解压到新目录，运行 `deployment\Start-MaaGakumasu-Admin.cmd`。
- 已使用独立 GKH 版本的用户保持 **Stable** 通道，通过 MFAAvalonia 内置 GitHub 资源更新升级。本版设为 **Latest**。
- 从旧 `vMAJOR.MINOR.PATCH+gkh.*` 组合版本首次迁移，仍需手动下载完整包。请勿切换到 Beta 或 Alpha，这两个通道可能选中编号更高的旧组合版本。
- 完整包从本项目 GitHub Releases 更新。Python 依赖按随包声明安装配套版本；RIS 引擎／数据更新仍使用原有入口。
- 更新后请核对“竞技场期数”。RIS 可能提前提供预览期，列表最高期数不一定是游戏当前期数。
- 详细说明见[使用手册](@REPOSITORY@/blob/main/guides/README.md)。

### 验证与已知问题

- 使用 MaaFramework 5.13.0 原生识别器回放 48 张真实失败画面，均恢复出上下排各 6 个卡框；同图调用中位耗时增加约 0.6 毫秒，识别次数不变。本次未完成新版整轮实机挑战。
- 沿用的图库已完成离线核验，真实竞技场位置与不同窗口下的校准仍待完成。本版 RIS 目录中部分新卡的普通态效果仍为空，识别参考更新不代表全部效果与模拟结果已完善。
- 正式发布不等于日常挑战最终验收完成；目前尚未完成同一版本连续两个游戏日、每天五场的测试。
- 竞技场连续多日自动完成全部挑战、540×960 窗口下的完整日常流程，以及部分卡片和读取耗时仍需验证。建议使用 720×1280 或更大窗口。
- 未完成对局和已保存的结果继续保留。升级不会清空记录或返还次数。
