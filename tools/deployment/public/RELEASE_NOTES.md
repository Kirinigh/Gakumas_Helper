## `@VERSION@` 竞技场识别改进与更新包精简

这次主要改善竞技场的卡牌和 P 道具识别，减少因名称读错、道具认错而中断读取的情况，同时精简了更新包。

### 本次更新

- **卡牌名称读错一个字时，会尝试纠正。** 例如名称中的“く”被读成“<”，或音符被读成相似字符时，程序会尝试找回正确卡牌；仍然无法确定时，会提示重新读取。
- **P 道具识别更有针对性。** 根据舞台类型和四个道具位置筛选可能出现的道具，减少把不可用于当前位置的道具认进去的情况，避免由此影响预计分数。
- **修复部分成长强化读取中断。** 减少把卡牌基础分数误当成强化效果而停止读取的情况。
- **资源更新遇到临时失败时，会再尝试一次。** 若只能继续使用已有资源，会明确提示，方便判断当前状态。
- **减少容易引起误解的日志提示。** 修正正常结束时的节点查询报错，以及彩色提示文字被误报为文件路径的问题。
- **精简下载包。** 移除重复运行文件和不参与日常使用的内容，保留现有功能所需组件。已有设置和保存记录继续保留。

### 更新后请先做这一步

**请重新读取一次竞技场己方编成，再查看预计分数或开始挑战。** 旧的读取结果不会自动纠正，重新读取后才能用上这次道具识别改进。

### 如何更新

- 已使用独立版本的用户，请保持 **Stable（稳定）** 通道，在客户端检查资源更新，升级到本版。
- 首次使用请下载 `MaaGakumasu-win-x86_64-@VERSION@.zip`，完整解压到新文件夹，再运行 `deployment\Start-MaaGakumasu-Admin.cmd`。
- 如果还在使用版本号带 `+gkh` 的旧版，请手动下载完整包。暂时不要切换到 Beta 或 Alpha 通道，以免选中旧版本。
- 更多操作说明和反馈方法见[使用手册](@REPOSITORY@/blob/main/guides/README.md)。

### 使用提醒

- 这次改进已通过已有样本检查，但还没有完成新版本的整轮实机挑战验证。个别卡牌和道具仍可能需要打开详情确认，不能保证所有识别错误都能自动纠正。
- 建议使用 720×1280 或更大的游戏窗口；较小窗口和部分新卡仍需继续验证。
- 预计分数仅供参考，部分新卡的效果数据仍可能不完整。更新不会重置挑战次数，也不会改写已经保存的历史结果。

### 可复核信息

- 公开源码提交：`@SOURCE_REVISION@`
- 完整包 SHA-256：`@PACKAGE_SHA256@`
- 文件校验信息随完整包提供：`GakumasHelper-release-@VERSION@.json`、`GakumasHelper-checksums-@VERSION@.txt`。
