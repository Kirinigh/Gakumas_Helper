## `@VERSION@` 上游同步与客户端兼容更新

同步 MaaGakumasu v1.5.0 的任务与资源更新，并纳入此前本地验证过的竞技场恢复、技能卡分类和客户端兼容修复。

### 本次更新

- **竞技场恢复与记录。** 修复遗留成员页、未关闭技能弹窗和跳过胜负页后的恢复；结果日志按任务身份关联，挑战次数按实际开战计数。补齐完整效果名称、短标题首字识别及图库缺卡时的有界详情兜底。
- **技能卡候选筛选。** 完整包包含 876 张技能卡的分类索引。读取器按舞台计划及卡组槽位收窄候选，保留既有图库向量与未知来源的兼容路径；这不是新一轮图库训练。
- **同步日常与培育改进。** 安排工作新增自动时长，修复工作页面切换等待；更新偶像卡配置与商店识别模板，补上 NIA 失败重试确认及删除、复制、变换操作的稳定等待。
- **启动与默认设置。** 资源版本及依赖配套匹配时跳过重复 pip 升级和镜像探测，保留错装修复与失败停止。完整包和 RIS 原有联网更新入口继续工作。
- **界面兼容。** 新增欢迎页、帮助页和默认布局。已有保存布局及用户实时视图选项保留；只有缺少实时视图设置时才使用默认关闭值，未保存布局时才应用新布局。其它启动和任务设置不重置。
- MaaFramework 与 Python 配套包继续使用 **5.13.0**，MFAAvalonia 保持 **2.15.2**，本次重建其兼容补丁。更新检查、日志导出和动态期数选项修复继续保留。

### 使用与更新

- 已使用独立 GKH 版本的用户保持 **Stable** 通道，通过 MFAAvalonia 内置 GitHub 资源更新升级。本版设为 **Latest**，无需手动选择本地 ZIP 或重新安装。
- 首次使用时下载 `MaaGakumasu-win-x86_64-@VERSION@.zip`，完整解压到新目录，运行 `deployment\Start-MaaGakumasu-Admin.cmd`。
- 从旧 `vMAJOR.MINOR.PATCH+gkh.*` 组合版本首次迁移，仍需手动下载完整包。请勿切换到 Beta 或 Alpha，这两个通道可能选中编号更高的旧组合版本。
- 完整包从本项目 GitHub Releases 更新；Python 依赖和 RIS 引擎／数据继续使用各自原有入口。升级后请核对竞技场期数、工作时长及偶像卡选择。
- 操作说明和反馈入口见[使用手册](@REPOSITORY@/blob/main/guides/README.md)。

### 验证与已知问题

- 上游合并、竞技场恢复与筛选已完成离线回归，三套资源通过实际 MaaFramework 5.13.0 加载。本轮没有执行 NIA、自动工作或整轮竞技场实机挑战，不能把离线通过视为完整实机效果或节拍验收。
- 新客户端默认值和布局保留逻辑经过真实方法离线回归及两次干净 Core 构建；最终包还按发布流程核对来源、字节一致性与启动情况。
- 正式发布不等于竞技场日常挑战最终验收完成；尚未完成同一版本连续两个游戏日、每天五场挑战的验证。新卡真实位置、跨窗口校准和 540×960 完整日常仍待验证，建议使用 720×1280 或更大窗口。
- RIS 目录中部分新卡普通态效果仍为空，分类和识别参考完善不代表全部效果与模拟结果已完善。本次没有新增 Linux 或 Android 平台支持声明。
- 原有配置、未完成对局及保存结果继续保留；升级不会清空记录或返还次数，已经消耗的次数不受更新影响。
