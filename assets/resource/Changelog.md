## `v0.3.2` 竞技场修复与框架升级

本次修复竞技场读取、停止响应和客户端更新中的问题，并调整模拟默认时限与参数说明。

### 本次更新

- 客户端框架与 Python 包同步升级到 **MaaFramework 5.13.0**。完整包覆盖更新后自动整理旧版本记录；启用依赖安装时，也会修复已装版本不匹配或覆盖不完整的情况。
- 点击停止后，读取与模拟会尽快退出，不再继续整队读取。正在执行的底层同步操作仍需返回后才能结束。
- 临时通信错误会先尝试页面提供的重试；详情意外消失时允许重新打开。单卡恢复机会用完后直接报告具体位置和已确认的名称（未确认时会明确标注），不再把前面已读成员全部重读一遍。
- 修复部分标题末尾音符 `♪` 识别缺失造成的详情确认失败，补齐“好印象强化”的文字解析。
- 模拟默认时限改为 **300 秒**，重新说明模拟次数、时限与胜率门槛的关系。升级时将旧默认 180 秒迁移为 300 秒，其他时限保留。
- 更新包下载失败时正确提示失败，并进行有限次数的重试；修复未应用更新却显示“已下载更新包”“更新任务完成”的情况。
- 精简竞技场界面日志，保留对手胜率、对局结果、失败卡位和本轮汇总；逐成员记录和详细错误仍写入日志文件。

### 使用与更新

- 下载 `MaaGakumasu-win-x86_64-v0.3.2.zip`，完整解压到新目录，运行 `deployment\Start-MaaGakumasu-Admin.cmd`。
- 已使用独立 GKH 版本的用户保持 **Stable** 通道，通过 MFAAvalonia 内置 GitHub 资源更新升级。本版设为 **Latest**。
- 从旧 `vMAJOR.MINOR.PATCH+gkh.*` 组合版本首次迁移，仍需手动下载完整包。请勿切换到 Beta 或 Alpha，这两个通道可能选中编号更高的旧组合版本。
- 完整包从本项目 GitHub Releases 更新。Python 依赖按随包声明安装配套版本；RIS 引擎／数据更新仍使用原有入口。
- 详细说明见[使用手册](https://github.com/Kirinigh/Gakumas_Helper/blob/main/guides/README.md)。

### 验证与已知问题

- 本次修复使用反馈日志、真实预览文字和自动化回归核验；这些检查不能代替新版本的完整游戏实机验收。
- 正式发布不等于日常挑战最终验收完成；目前尚未完成同一版本连续两个游戏日、每天五场的测试。
- 竞技场连续多日自动完成全部挑战、540×960 窗口下的完整日常流程，以及部分卡片和读取耗时仍需验证。建议使用 720×1280 或更大窗口。
- 未完成对局和已保存的结果继续保留。升级不会清空记录或返还次数。
