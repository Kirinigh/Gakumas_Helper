# 常见问题

## 如何更新？

已使用独立 GKH 版本时，保持 Stable 通道，通过客户端内置 GitHub 资源更新升级。完整说明见[更新与回滚](https://github.com/Kirinigh/Gakumas_Helper/blob/main/guides/UPDATE_AND_ROLLBACK.md)。

## 卡住、报错或识别异常时如何反馈？

使用客户端日志导出入口，保留与问题相关的日志、失败记录及可用图片；分享前检查账号信息等隐私内容。说明所选任务、游戏版本、窗口尺寸、错误提示和发生步骤，按[故障排查](https://github.com/Kirinigh/Gakumas_Helper/blob/main/guides/TROUBLESHOOTING.md)自查后，通过本项目反馈入口提交。

## 更新后的布局或实时视图会重置吗？

已保存布局和实时视图选择保持原值。只有没有保存布局时才采用资源默认布局；缺少实时视图设置时才采用默认关闭值。此设置与游戏任务、自动更新或启动开关相互独立。

## 自动培育与竞技场都已完整验收吗？

没有。自动培育沿用上游能力，竞技场也仍有窗口、新卡和连续运行验证待完成。请阅读[使用手册](https://github.com/Kirinigh/Gakumas_Helper/blob/main/guides/README.md)及本版更新公告中的已知限制。
