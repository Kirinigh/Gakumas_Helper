## `v0.6.1` 竞技场选敌更快，读取与更新更顺畅

这次主要减少竞技场选敌时的等待，并改善卡牌详情读取、奖励弹窗处理和资源更新提示。

### 本次更新

- **找到合适的对手后，可以更早开始挑战。** 依次计算对手胜率，计算期间继续读取下一位；找到首个达到胜率门槛的对手后，就结束后续读取。
- **新增“快速选择下限”，默认 20%。** 前两名对手都未达标，且保守胜率下限都不超过此值时，会直接挑战 3 号，不再计算其胜率。这样可减少等待，但 3 号也可能更强；已有手动设置会继续保留，设为 0 也不是关闭此功能。
- **改善升级卡牌详情读取。** 已确认是升级卡牌、但详情文字漏掉加号时，会进行有限次数的确认与重开，减少误判。
- **改善奖励弹窗处理和失败提示。** 关闭阶段积分奖励时不再依赖模糊的背景胜负文字；读取失败后的提示会保留最初原因，方便排查。
- **竞技场资源更新可复用客户端已配置的 GitHub 令牌。** 无需为竞技场另填一次；认证请求与匿名请求的等待状态分开处理。
- **简化设置页。** 移除没有实际接入读取流程的“本地画面采集”选项。读取失败时仍会自动保留有限的已有画面与错误信息，仅保存在本机，不会自动上传。

### 如何更新

- 已使用独立版本的用户，请保持 **Stable（稳定）** 通道，在客户端检查资源更新。从 0.6.0 升级时，条件合适可只下载变化的文件；不满足条件时自动使用完整包。
- 首次使用请下载 `MaaGakumasu-win-x86_64-v0.6.1.zip`，完整解压到新文件夹，再运行 `deployment\Start-MaaGakumasu-Admin.cmd`。
- 如果还在使用版本号带 `+gkh` 的旧版，请手动下载完整包。暂时不要切换到 Beta 或 Alpha 通道，以免选中旧版本。
- 更多操作说明和反馈方法见[使用手册](https://github.com/Kirinigh/Gakumas_Helper/blob/main/guides/README.md)。

### 使用提醒

- 更新后建议重新读取一次竞技场己方编成；旧读取结果不会自动纠正。
- 本版已进行离线回归与独立启动检查，还没有完成整轮实机挑战验证，也尚未完成真实在线升级验证；不能保证所有识别错误都能自动纠正。预计分数仅供参考，部分新卡和较小窗口仍需继续验证。
- 更新不会重置挑战次数，也不会改写已经保存的历史结果。
