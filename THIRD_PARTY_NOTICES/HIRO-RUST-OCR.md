# Hiro, native exam engine and OCR notices

This release includes Python code from [matto49/hiro-gakumas-hero](https://github.com/matto49/hiro-gakumas-hero/tree/8380622a467cc30296c91b79dba4348166ef8d12), release metadata version 0.2.0, at revision `8380622a467cc30296c91b79dba4348166ef8d12`. Hiro declares `GPL-3.0-or-later`. Its original license and attribution are in the release's `GakumasHelper-corresponding-source-v0.9.0.zip` under `hiro/LICENSE` and `hiro/README.md`. The binary package also retains Hiro's license alongside its runtime. The upstream project credits the development and device integration of [kotones-auto-assistant (KAA)](https://github.com/XcantloadX/kotones-auto-assistant) and the projects named in its README. The original Python runtime and the packaged project adapter are distinct source paths. The GakumasHelper source release contains the adapter for Maa, Idol Road and cultivation.

The included Rust exam crate `gakumas_exam_rs` 0.1.0 comes from the same pinned Hiro tree under `vendor/gakumas-player/gakumas_exam_rs` and declares MIT in its `Cargo.toml`. The corresponding-source attachment includes the patched crate and its exact `Cargo.lock`. GakumasHelper's four patches implement Tower multi-stage choices, live state updates, stamina search and previous-card trigger ordering. The patch series is taken from GakumasHelper revision `1d9c14e91a381e60b13a052bcf3c24f22b616d44`. The attachment contains the original upstream license, exact patch series and build directions.

Game images, screenshots already incorporated as recognition templates, fonts, game-derived master records and Tower floor bindings retain their respective provenance and ownership. Hiro's upstream [asset notice](https://github.com/matto49/hiro-gakumas-hero/blob/8380622a467cc30296c91b79dba4348166ef8d12/assets/pack/README.md) addresses those materials separately from source code. The data paths, component identities and byte checks are recorded in the packaged runtime manifest. The nested Tower master uses [vertesan/gakumasu-diff](https://github.com/vertesan/gakumasu-diff/tree/d31baf6608ee4553091f28446f628cd3ad66ff01) at revision `d31baf6608ee4553091f28446f628cd3ad66ff01`; the binding input uses the [Hiro knowledge benchmark](https://hiro.matto.top/gkbench/api/sets/idolroad/saves).

The runtime adapters and notices for [GKMSUINet](https://github.com/yuzeis/GKMSUINet) retain their upstream MIT attribution to yuzeis.
