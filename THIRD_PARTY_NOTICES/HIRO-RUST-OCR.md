# Hiro, native exam engine and OCR notices

GakumasHelper v0.9.3 pins [matto49/hiro-gakumas-hero](https://github.com/matto49/hiro-gakumas-hero/tree/6e7bbd59a7ca2a66c1f1615cb9bd8e2e3b3ede93) at `6e7bbd59a7ca2a66c1f1615cb9bd8e2e3b3ede93`. Hiro declares AGPL-3.0-or-later for its own code and retains GPL-3.0 for its KAA-derived files. Both original license files are included alongside the runtime. Hiro credits [kotones-auto-assistant (KAA)](https://github.com/XcantloadX/kotones-auto-assistant) and the projects named in its README. The upstream source and the GakumasHelper adapter remain separate. The packaged runtime manifest identifies these inputs. The release's corresponding-source attachment contains the exact distributed Hiro Python source and the source and build instructions for the Rust extension.

The included Rust exam crate `gakumas_exam_rs` 0.1.0 is derived from the pinned Hiro tree under `vendor/gakumas-player/gakumas_exam_rs`. Its upstream Cargo manifest declares MIT. The GakumasHelper build uses five patches for Tower choices, live state, stamina search, previous-card ordering and qualified encore deck return. The corresponding-source attachment records the native source and output identities.

Game images, screenshots already incorporated as recognition templates, fonts, game-derived master records and Tower floor bindings retain their respective provenance and ownership. Hiro's upstream [asset notice](https://github.com/matto49/hiro-gakumas-hero/blob/6e7bbd59a7ca2a66c1f1615cb9bd8e2e3b3ede93/assets/pack/README.md) addresses those materials separately from source code. The remaining original game images derive from the three fixed `game-images-b9577da` archives identified in Hiro's release notices. The data paths, component identities and byte checks are recorded in the packaged runtime manifest. The nested Tower master uses [vertesan/gakumasu-diff](https://github.com/vertesan/gakumasu-diff/tree/edc305aac3ac0204806c96164ce36fb795ba81e1) at revision `edc305aac3ac0204806c96164ce36fb795ba81e1`; the binding input uses the [Hiro knowledge benchmark](https://hiro.matto.top/gkbench/api/sets/idolroad/problems).

The GakumasHelper OCR worker source and build script are in this release's corresponding-source attachment under `gkh/tools/task275/simd_ocr/`. The worker uses [SimdPaddleOCR](https://github.com/sdcb/SimdPaddleOCR/tree/102ef0644799ffda509febf61299c8e7cb9c6f4e) at `102ef0644799ffda509febf61299c8e7cb9c6f4e` and [SimdOnnx](https://github.com/sdcb/SimdOnnx/tree/bd861ebe200ee66bb87d88481c726798a2a3bf64) at `bd861ebe200ee66bb87d88481c726798a2a3bf64`. Both upstream licenses and the SimdPaddleOCR notices are included under the package's `data/ocr/` and the attachment's `ocr-license/`. The worker project retrieves the fixed upstream source archives and NuGet packages identified by the included project and publish script.

The runtime adapters and notices for [GKMSUINet](https://github.com/yuzeis/GKMSUINet) retain their upstream MIT attribution to yuzeis. The v1.1 encoder and resources are recorded in `GKMSUINet.md`, and the v2.1 runtime includes its notice and source manifest under `data/hif_fast/uinet21/1fc50378753bd35fb239bebb77cb315c019915ff/`. The code licenses identify their own scope. Model weights, derived master records and game graphics retain their separate provenance.
