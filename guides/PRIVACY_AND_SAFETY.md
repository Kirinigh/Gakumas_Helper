# 隐私与安全

## 自动化边界

Gakumas Helper 只使用截图、图像识别、OCR、离线模拟和正常界面输入。它不会：

- 修改游戏或 DMM 文件；
- 注入、挂钩游戏进程或读取 `gakumas.exe` 内存；
- 读取或保存 DMM 账号密码；
- 关闭 Windows Defender 或 UAC；
- 在身份、页面或结果不唯一时猜测并继续挑战。

任何真实鼠标、键盘或触控输入都必须由管理员 Maa/MaaFramework 输入进程执行。管理员父进程不自动证明实际输入端权限；程序会在关键输入前复核，权限不匹配就停止。

## 本机数据

竞技场的权威缓存、Worker 校准和挑战记录位于当前安装目录的 `.local/arena-win-rate`。竞技场读取失败时，会将最多六张已有画面和错误信息保存在 `.local/arena-win-rate/reader-failures`。培育功能的可选截图/ROI 采集位于 `.local/runtime-data`。这些数据不会自动上传或远端备份。

培育功能的本地画面采集默认关闭。启用后的图像保留规则如下，不适用于竞技场独立的失败证据目录：

- 普通截图/ROI 默认保留 14 天，最多 512 MiB；
- 失败现场默认保留 30 天，最多 512 MiB；
- 图像合计最多 1 GiB；

文字日志每日轮转压缩，默认保留 14 天。

这些文件可能包含游戏画面、己方或对手编成、时间和本机路径，应按私人数据处理。

## 公开包不包含什么

发布流程只从允许清单生成独立的单提交源码快照，并对源码、候选目录和最终 ZIP 执行隐私扫描。公开包不会故意携带：

- 用户配置、日志、缓存、截图、ROI 或对局记录；
- 账号、Cookie、令牌、密钥或凭据；
- 用户目录、本机路径、内网地址或硬件地址；
- 私有训练样本、原始用户截图或可链接的私有样本指纹；
- 内部开发历史、任务管理或会话记录。

第三方许可证中的法定作者署名和公开依赖自身的构建元数据会按许可证保留，它们不属于当前用户信息。

## 公开反馈前脱敏

GitHub Issue、评论和附件默认公开。提交前必须移除：

- 账号名、玩家 ID、邮箱、Cookie、令牌、设备名和用户目录；
- 完整 `config`、`appsettings.json`、`.local`、日志包和崩溃转储；
- 未打码游戏截图、原始 ROI、己方/对手缓存和训练样本；
- 与问题无关的本机路径、时间线或硬件标识。

优先提供前台错误码、任务入口、版本、分辨率、参数和脱敏后的最小日志摘录。识别问题先写舞台/成员/槽位与已知卡或 P 道具 ID；截图不是必填。维护者如果确实需要图像，会在存在合适的非公开传输方式后另行说明；在此之前不要把私人画面放入公开仓库。

### 临时竞技场诊断

包含本批诊断补丁的安装包在2026年11月1日00:00（北京时间）前默认启用有限采样，用于确认卡图候选、道具返回和动作中断原因。图像只复用任务已有的游戏截图，含卡组、成员信息和识别文字；动作探针只记动作名称、起止状态、耗时及异常类型，不记录配置或令牌。没有自动上传。

图像样本保存在 `.local/arena-win-rate/reader-failures/probe-*`，与原日志一并导出。每个安装目录共20组、128 MiB；其中最多16组卡图，另留4组给道具返回（3组失败、1组成功对照）。重启不重置图像限额，写入失败停止探针，不影响任务结果。到期停止新增，已保存的样本仍可导出；不会在到期时删除现有证据。动作起止日志每个Agent进程至多256对，沿用文字日志14天保留规则。

若要关闭额外采样，可在安装目录 `.local/arena-win-rate/recognition-probe.json` 写入 `{"enabled": false}` 后重启客户端。本地已有设置优先于随包默认值。关闭探针不关闭原有故障日志；分享前请检查日志包，并只通过已约定的非公开方式发送。

## 风险与停止条件

- “竞技场胜率分析并挑战（单次）”和“每日挑战 → 胜率选敌”可能真实消耗挑战次数；
- 无达标对手时选择预测胜率最高者，仍标为未达标，不修改设置的门槛；
- 已支持的读取、页面或通信故障会自动有界恢复；仍无法确认输入或结果、模拟失败、跨 `04:00` 或权限不足时停止；
- 结算只要求三个舞台赢家和总体胜负，分数异常不阻断；结果确认并保存后才离开结果页，未恢复的对局保留待决记录并阻止新挑战；
- 统计门允许一定程度的保守虚低，尽可能避免虚高，但不能消除游戏随机性或所有未知界面变化。

当前版本按非预发布 Latest 发布。竞技场仍有未完成的实机与连续日常验收，具体范围见[竞技场指南](ARENA_WIN_RATE.md)；请保留旧版本作为回滚路径。
