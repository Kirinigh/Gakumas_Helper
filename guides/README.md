## 最短安全路径

1. 使用独立目录安装，不覆盖任何既有版本。
2. 以管理员身份启动 Maa，并保持游戏已经登录。
3. 首次只运行“重算竞技场己方总分”。
4. 确认缓存摘要、期数与编成正确后，再运行会挑战的任务。
5. 遇到不唯一或不完整提示时停止；不要通过降低识别阈值、删除待决记录或反复点击绕过。
6. 反馈时只提交脱敏后的最小复现信息。
